# JS Boy — Mentor Pack de evolução

Objetivo: dominar o fluxo existente, corrigir fragilidades verificadas e evoluir por entregas pequenas. Este README é da mentoria; não substitui o README principal.

## Uso

Coloque esta pasta em `<repositorio>/mentoria/`. Abra o repositório no Antigravity e cole `prompts/00_INICIAR.md`. Não copie o kit do outro projeto para a mesma pasta.

Leia primeiro DIAGNOSTICO.md e siga DESAFIO_EVOLUCAO.md. Antes de retomar uma sessão use `prompts/01_RETOMAR.md`. Para um erro use `prompts/02_DEBUG.md`.

Snapshot de referência: `1e121184055a4c41e275b4ff5919bf56ce2870ff`. A branch local e mudanças não commitadas têm de ser verificadas antes da primeira correção.

Primeiro objetivo: rastrear a criação de uma entrega da tela ao banco e reproduzir um fluxo com usuários de teste.

Não há fase concluída previamente neste kit. Há achados de leitura, propostas e uma trilha para obter evidências.
